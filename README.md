# 1_44MB

## RPG NPC会話の編集

`build/rpg_editor.exe` でNPCをクリックすると、NPC Inspectorが開きます。会話は1行ずつ上から順に表示され、行をクリックして入力・Backspaceで編集できます。行が多い場合は会話リスト上でマウスホイールを使ってスクロールします。会話行はドラッグで並び替え、右クリックで削除できます。`Add dialogue line` で行を追加し、`Save NPC dialogue` または `S` で保存した内容は `rpg_version.exe` の会話に反映されます。インスペクター右上の `×` ボタンで閉じられます。会話編集中は、日本語IMEの入力を優先してエディター用ショートカットを無効にし、変換候補を選択中の会話行の近くに表示します。

NPC Inspectorの `Edit dialogue` ボタンで会話編集画面を開きます。編集中は画面全体が黒い半透明で覆われ、会話編集画面だけを操作できます。
会話編集画面上部の `Font - / +` で文字サイズを変更できます。会話行ブロックの高さとブロック間隔は文字サイズ・内容量に合わせて自動で変わり、横幅を超える文章は自動改行して表示されます。

会話に新しく入力した日本語も、エディターとRPG版でそのまま表示されます。
会話行内をクリックすると、その位置にカーソルを置いて文字を挿入できます。左右キー、Home/End、Backspace/Deleteでも編集できます。
同じ会話行を横方向へドラッグすると文字範囲を選択できます。選択部分は入力で置換、Backspace/Deleteで一括削除できます。

## RPG版

`build/rpg_version.exe` は横スクロール版とは独立したRPG版です。人型の主人公を WASD / 矢印キーで動かし、NPCの近くで `E` を押すと会話を表示できます。

主人公は足元の当たり判定でマップ外へ出られず、NPCには重ならないようになっています。NPCの近くでは `[E] Talk` が表示されます。

RPG版は空と地面を持つ横視点です。主人公とNPCの足元は地面に接し、主人公は `W` / `Space` でジャンプできます。

会話中は主人公を操作できません。会話UIは話者名と本文を分けて表示し、`E` で閉じます。

NPC会話は複数ページに対応しており、`E` で次の内容へ進み、最後のページで会話を閉じます。

RPG版のNPC案内と会話本文は日本語で表示されます。

`build/rpg_editor.exe` はRPG版専用エディターです。主人公またはNPCをクリックしてからマップをクリックすると配置でき、`S` で保存した配置はRPG版に反映されます。

RPGエディターでは `B` でブロック編集モードに入り、左クリックで設置・右クリックで削除できます。`S` で保存したグリッドはRPG版にも反映されます。

RPG版はマップ1〜3を横に連結しています。RPGエディターでは `1` / `2` / `3` で編集するマップを切り替えられます。

RPG版では `C` で、主人公へ追従するカメラと現在のマップ中心へ固定するカメラを切り替えられます。

初期状態はマップ中心固定カメラです。

RPGエディターで主人公を選択すると移動速度を調整できます。RPG本体の左下には現在いるマップ番号が表示されます。

グリッドは 48px 四方（72列 × 16行）です。

プレイ中に `R` でマス統合モードを開き、マウスで正方形をドラッグして `Enter` を押すと、範囲内の値の平均を四捨五入した一つの大きなマスへ統合します。決定した統合はそのプレイ中には戻せません。`Esc` は未確定の選択をキャンセルします。

## マス単位のステージ編集

エディターで `Global` を開き、`Grid edit` を ON にします。`0`（空）、`1`（地面・壁）、`2`（敵スポーン）を選んでマップ上のマスをクリックすると、マスの値を置き換えられます。`2` は置いた全マスに敵を配置し、保存内容はゲーム本体にも反映されます。

raylib を使った 2D 横スクロールゲームの土台です。

ゲーム本体の主人公は `assets/Sprite/ZIPPER.png` の 5 フレームアニメーションを使用します。移動中にフレームが切り替わります。画像は `assets` に置いたまま参照し、`build` にはコピーしません。

敵キャラは3体おり、`assets/Sprite/FILE.png` を使用して指定された巡回範囲を左右に往復します。従属化後の補間移動だけはプレイヤーの移動速度を上限にし、最初の敵は「設定した間隔 × プレイヤー倍率」の位置を目標に、2体目以降はひとつ前の敵との設定間隔を取るよう追従します。k体目の目標は、プレイヤーの `k×0.05秒` 前の位置から計算し、毎フレーム更新します。

## フォルダ構成

- `src/Play`: ゲーム本体
- `src/Editor`: エディター
- `src/Shered`: 両方から利用するプレイヤー・ステージ
- `assets/Sprite`: スプライト画像
- `assets/Settings`: エディターで保存するゲーム設定
- `assets/Fonts`: 日本語表示用フォント（`NotoSansJP-VF.ttf`）
- `build`: 実行ファイルと必要な DLL

## ステージグリッド

ステージは96px四方のグリッドで管理します。標準サイズのプレイヤーと敵は1マス内に収まります。

- `0`: 空白
- `1`: 地面・壁ブロック
- `2`: 敵がいるマス（敵の移動に合わせて更新）

## 操作

- `A` / `←`: 左へ移動
- `D` / `→`: 右へ移動
- `Space`: 主人公のアクションを一度再生。アニメーション中は移動できず、220px以内の敵を従属化する。紫の円が判定範囲
- `Q`: グリッド確認モードを切替。画面を淡くし、各マスの `0` / `1` / `2` を表示
- `Esc`: 終了

## エディター

`build/side_scroller_editor.exe` を起動すると、主人公の見た目を確認・変更できます。

- 主人公を左クリックするとインスペクターを表示します。
- インスペクターの「PNG を選択」から PNG ファイルを指定すると、その場で見た目に反映されます。
- プレイヤーと敵は標準で1.5倍の大きさで表示されます。各インスペクターの `Scale` で0.5〜3.0倍に変更できます。
- 敵を左クリックすると敵インスペクターを表示し、追従間隔・補間速度・従属時の色を変更できます。
- インスペクターを開いたクリックはボタン操作として扱わず、インスペクター外を左クリックすると閉じます。
- 追従間隔と補間速度はスライダーのほか、右側の数値欄をクリックしてキーボード入力でも変更できます。最初のクリック後に数値を入力すると値全体を上書きし、同じ欄をもう一度クリックすると、その桁の位置から編集できます。Enterで確定します。保存結果は敵インスペクター下部に表示されます。
- プレイヤーと敵の `Scale` 入力欄は独立しており、片方を編集した値がもう片方へ引き継がれることはありません。
- 「設定を保存」で `assets/Settings/enemy_settings.cfg` に保存され、保存成功時は敵インスペクターが閉じます。ゲーム本体の次回起動時に反映されます。
- Playボタンでエディター内の動作確認を開始できます。停止中は敵は動かず、Play中はゲーム本体と同様に `A` / `D` と `Space` を操作できます。
- エディターでも `Q` でグリッド確認モードを切り替えられます。
- Playボタン横の `Global` を押すと全体インスペクターを開けます。`Grid opacity` で、グリッド確認モード時に画面を淡くする度合いを変更・保存できます。

## ビルド（MSYS2 MinGW64）

MSYS2 MinGW64 シェルで、プロジェクト直下から次を実行します。

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic -Isrc/Shered \
  src/Play/main.c src/Shered/player.c src/Shered/stage.c \
  src/Shered/enemy.c src/Shered/enemy_group.c src/Shered/enemy_settings.c src/Shered/game_font.c \
  -o build/side_scroller.exe -lraylib -lopengl32 -lgdi32 -lwinmm

gcc -std=c11 -Wall -Wextra -Wpedantic -Isrc/Editor -Isrc/Shered \
  src/Editor/main.c src/Editor/editor_ui.c src/Editor/file_dialog.c \
  src/Shered/enemy.c src/Shered/enemy_group.c src/Shered/enemy_settings.c \
  src/Shered/game_font.c src/Shered/player.c src/Shered/stage.c \
  -o build/side_scroller_editor.exe \
  -lraylib -lcomdlg32 -lopengl32 -lgdi32 -lwinmm
```

実行ファイルと必要な DLL は `build` にまとめます。ゲーム本体を起動するには、`build` と同じ階層に `assets` フォルダが必要です。
