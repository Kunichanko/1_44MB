# 1_44MB

raylibで作成した2D横スクロールゲームと、そのRPG版エディターです。

## 実行ファイル

- `build/rpg_version.exe`: RPGゲーム
- `build/rpg_editor.exe`: RPGステージ・キャラクター・会話の編集

## RPGエディター

- `Item Property` の受容体: 1ブロックにつき1個を辺に設置すると、導線の始点と未延長の端点を自動作成します。通常モードでは、受容体が付いたブロックを押して離すと設置辺を切り替え、押したままドラッグすると導線を延長できます。
- 導線・受容体: 追加、導線端点のドラッグ、受容体の辺切替は、ブロック編集モードの `Ctrl` + `Z` で戻せます。

- `1`〜`6`: 編集するマップを切替
- `B`: ブロック編集モード。左クリックまたはドラッグで選択中ブロックを配置、右クリックまたはドラッグで削除。画面下部の枠付きパレットで種類を選び、別枠のインベントリ名をクリックした一覧または左右矢印でインベントリを切替。各インベントリには10種類まで登録できる。`Earth`には、半マス幅の縦穴・横穴を持つ通常ブロックもある。`Reference Object`では効果を持たない1マスの`FILE.png`を選べる。Fileは通常モードでクリックするとインスペクターを開き、`Select .txt file`で`assets/Files`を初期表示したPC内のファイル選択画面を開ける。絶対パスを入力または`Ctrl`+`V`で貼り付けることもできる。配置済みのFileは空きマスへドラッグ移動でき、ゲーム中は近づくとファイル名と`E`の案内を表示し、`E`で内容を開く。表示中は会話中と同じく移動できない。`Effect`には跳ねるブロック、減速ブロック、横2マスの跳ねるブロック、L字3マスの跳ねるブロックがあり、配置済みのものはドラッグで空きマスへ移動できる。特殊ブロックは占有マス形状に従って配置・移動・削除・Undoされるため、構成マスのどこを操作しても全体を扱う。`Item Property`はブロック上へ星アイテムを付与し、配置後に星をクリックするとインスペクターを開く。導線を選ぶと、クリックした始点ブロックと隣接する終点ブロックを接続する。始点・終点を隣接ブロックへドラッグすると通過したマスをつなぎ、既存の導線上へ動かすとその地点まで短縮する。ステージ会話のパネルは表示しない
- `Effect`内のドア: 縦3マスのドアを配置。通常モードでドアをクリックするとインスペクターを開き、`Open` / `Close`で状態を切替。開状態は先頭マスが光る
- `Attachment`: 電波発生装置とデータボタンを、既存ブロックのクリック位置に近い床・壁・天井の辺へ取り付ける。ブロック編集モードでは、設置済みの部品をドラッグして近くのブロック辺へスナップ移動でき、部品を右クリックすると土台を残して削除できる。データボタンはプレイヤーが踏んだ瞬間に、配置済みの電波発生装置からデータ弾を1つずつ射出する。設置内容は全体保存でプレイ画面にも反映される
- 電波発生装置: 通常モードで装置をクリックすると、実弾の `Size / file` と `Speed / KB`、プレビュー専用の仮想ファイル数・容量、プレビューON/OFFを調整できる。プレビュー容量欄はクリックしてKB単位の数値を入力し、Enterで確定する。プレビューは実弾と同じ計算式で見た目と速度を決めるが、電気化してもギミックを動かさない。実際のデータ弾が受容体に当たると、同じ弾が電気として接続された導線を末端まで進み、通過したドアを開く。ブロックモードでは黄色い経路端点をドラッグして、ブロック上を含むマスへ軌道を設定する。
- 左上の `Settings`: 全体設定を表示し、電気化したデータ弾が次の導線マスへ進む遅延時間を変更する。`S` で全体保存する。
- ドアに重なる導線: ドア内の部分を薄く表示し、マス境界の接点を強調
- 通常モードの`Add event`: 配置後にマップをクリックして、その地点で一度だけ発生するイベントを置く。`Shift`+ドラッグで移動、右クリックで削除
- `S`: ブロック・星アイテムを含む編集内容をまとめて保存
- インスペクター: ボタン・入力欄以外の空白部分をドラッグして移動
- Zipper選択表示: エディターではホバーで淡い青、選択中は濃い青で表示。ゲーム中は追従状態のZipperだけ同じクリック選択表示を行う
- File選択表示: `FILE.png`もZipperと同じく、ホバーで淡い青、クリック選択で濃い青になり、別の場所のクリックやプレイヤー移動で解除される
- ゲーム中のFile操作: `FILE.png`をダブルクリックすると内容を開く。ドラッグ中はカーソルに追従し、元の位置には半透明のFileを表示する。Zipper上で離すとそのプレイ中はステージから消えて、実Zipperフォルダ内の`Inbox`へコピーされる。ほかの場所で離すと元の位置へ戻る
- Zipperディレクトリ: ZipperをダブルクリックするとWindows Explorerを開く。ブロックへ停止中にダブルクリックすると、そのブロックに対応する実objectフォルダを開く
- 導線の端点編集は、ほかのグリッド経路機能でも使える共通の経路編集として実装
- 星アイテムの未保存変更: 画面上部とアイテムインスペクターに赤字で表示
- `Ctrl` + `Z`: ブロック編集時は直前のマス変更・星アイテムの付与を戻す。星付きブロックの削除は、ブロックと星を同時に復元する。インスペクター表示中は、編集値・ステージ移動・対象選択・モーダル遷移を戻す。履歴は50件までで、エディターを閉じた後も維持
- `Revert saved`: 未保存の編集内容を直近の保存状態へ戻す
- プレイヤー、NPC、Zipperを選択: クリックでインスペクターを開き、ドラッグで位置を変更
- 共通ドラッグ: 設置物・特殊ブロック・キャラクター・`FILE.png` は、同じ移動しきい値でドラッグを開始し、ドラッグ中はインスペクターを閉じます。
- 各キャラクターのインスペクター: `Save`でそのキャラクターの位置・大きさだけを保存。隣の`Revert`でその保存状態へ戻す
- Zipper設定: 位置・大きさ・調べるFunctionをZipper専用設定として管理
- Zipperを調べる: 設定したFunction列が完了すると主人公へ追従
- 未保存の変更がある状態で閉じる: 保存して終了／保存せず終了／キャンセルを選択。`Show details`で未保存項目を確認し、一覧はマウスホイールでスクロール

NPCの `Edit dialogue` では通常会話を、`Edit examine` では調べる機能を編集できます。Examineではタイトル付きの会話機能を管理し、各機能ごとに会話を編集します。

- `Edit dialogue`: NPCに話しかけた時の会話を編集
- `Edit examine`: NPCを調べた時の機能一覧を開く
- Examine一覧: 1クリックで会話機能を選択してタイトルを編集、ダブルクリックで会話内容を編集。`Add function` で機能タイプを選択して追加、右クリックで削除、会話ブロックをドラッグして順番変更
- Move機能: 実際のゲームでは選択対象の本体を移動させる。エディターのプレビューでは同じ見た目のダミースプライトだけを移動させ、実際の配置は変更しない。Moveサイドパネルの外側を左クリックして目的地、右クリックしてプレビュー専用の開始位置を設定。時間を調整し、`Play preview` で動きを確認。各`Save`の隣の`Revert`はその編集内容だけを戻し、全体保存は`S`で行う。サイドパネルの空白部分はドラッグで移動可能
- モーダル画面: `Tab` で一つ前の画面へ戻る。Examineの会話編集は一覧へ、一覧ではエディター画面へ戻る
- Zipper: インスペクターの `Edit examine` から調べる機能を編集

## RPGゲーム

- 移動: `A` / `D` または矢印キー
- ジャンプ: `W`
- Zipper射出: Zipperを調べ終えた後、追従中に`Space`。プレイヤー位置からマウスカーソル方向へ直進し、ブロックに当たると停止します。停止後にもう一度`Space`で追従へ戻ります。射出・帰還速度と、射出→帰還を繰り返すプレビューはZipper Inspectorで設定できます。
- Zipperのobjectフォルダ: 電波装置・ボタンなどの設置物には、配置情報を記録したobjectフォルダを`Stage/Objects/attachments`へ用意します。設置物に接触中に`Inbox/zipper_animate.cmd`を実行すると、通常ブロックと同じ一時コピー・変更通知・同期を利用します。紐づくファイルを持つ設置物は金色で、通常ブロックはそのマス自体を強調表示します。Zipperのダブルクリックは常にZipperフォルダを開きます。
- 射出中のZipper: ブロック、`FILE.png`、電波発生装置、データ弾に接触すると停止します。データ弾へ接触した場合は消えるまで追従し、壁へ衝突して消えた弾には壁際へ残り、空中で消えた弾からは追従状態へ戻ります。
- データボタン: `Attachment` パレットから既存ブロックの辺へ取り付けます。プレイヤーが踏むと、ボタン押下通知を発行します。現時点では電波発生装置がこの通知を受信し、データ弾を射出します。
- グリッドのブロックと閉じたドアは壁として当たたり、開いたドアは上1マスだけ壁として残り、下2マスはプレイヤーとデータ弾が通行できます。
- NPC会話: `E`
- NPC・Zipperを調べる: `I` で開始、`E` で進行。一度完了すると、そのゲーム中は再実行しない
- 星アイテム: 近づくと取得し、入手メッセージを表示
- カメラ切替: `C`

RPGのステージ・会話・配置物・履歴は `assets/Settings/Stage`、Zipperの設定は `assets/Settings/Zipper` に保存します。プレイ中に回収したテキストFileは `Settings/Zipper/Inbox`、objectフォルダは `Settings/Stage/Objects` を一時利用します。ゲーム開始時と終了時には、これらとZipper直下の一時objectコピーを確認して削除します。画像やフォントなどの外部ファイルは `assets` に置き、`build` には追加しません。
- `build`: 実行ファイルと必要な DLL
- `experiment`: 実験用スペース（各自ローカル。`.gitignore` 済み。詳細は `experiment/README.md` と `experiment/RULES.md`）

## ステージグリッド

ステージは96px四方のグリッドで管理します。標準サイズのプレイヤーと敵は1マス内に収まります。

- `0`: 空白
- `1`: 地面・壁ブロック
- `2`: 敵がいるマス（敵の移動に合わせて更新）

## 操作

- `A` / `←`: 左へ移動
- `D` / `→`: 右へ移動
- `Space`: 主人公のアクションを一度再生。アニメーション中は移動できず、220px以内の敵を従属化する。紫の円が判定範囲
- `Q`: グリッド確認モードを切替。画面を淡くし、各マスの `0` / `1` / `2` を表示
- `Esc`: 終了

## エディター

`build/side_scroller_editor.exe` を起動すると、主人公の見た目を確認・変更できます。

- 主人公を左クリックするとインスペクターを表示します。
- インスペクターの「PNG を選択」から PNG ファイルを指定すると、その場で見た目に反映されます。
- プレイヤーと敵は標準で1.5倍の大きさで表示されます。各インスペクターの `Scale` で0.5〜3.0倍に変更できます。
- 敵を左クリックすると敵インスペクターを表示し、追従間隔・補間速度・従属時の色を変更できます。
- インスペクターを開いたクリックはボタン操作として扱わず、インスペクター外を左クリックすると閉じます。
- 追従間隔と補間速度はスライダーのほか、右側の数値欄をクリックしてキーボード入力でも変更できます。最初のクリック後に数値を入力すると値全体を上書きし、同じ欄をもう一度クリックすると、その桁の位置から編集できます。Enterで確定します。保存結果は敵インスペクター下部に表示されます。
- プレイヤーと敵の `Scale` 入力欄は独立しており、片方を編集した値がもう片方へ引き継がれることはありません。
- 「設定を保存」で `assets/Settings/enemy_settings.cfg` に保存され、保存成功時は敵インスペクターが閉じます。ゲーム本体の次回起動時に反映されます。
- Playボタンでエディター内の動作確認を開始できます。停止中は敵は動かず、Play中はゲーム本体と同様に `A` / `D` と `Space` を操作できます。
- エディターでも `Q` でグリッド確認モードを切り替えられます。
- Playボタン横の `Global` を押すと全体インスペクターを開けます。`Grid opacity` で、グリッド確認モード時に画面を淡くする度合いを変更・保存できます。

## オブジェクトフォルダ

設置物とデータ弾は固有の実フォルダを持ち、Zipper のアニメーション中はそのフォルダ本体を `Settings/Zipper/Inbox` へ移動します。データ弾が消える際には、発射後に追加されたファイルだけを File.png として地面へ落として保持します。

電波発生装置が出すデータ弾は、弾フォルダ内のファイル数から1を引いた値で大きさ、合計容量で速度を決めます。発射時には装置側のメタデータ・ファイルを弾フォルダの `parent` へ複製し、弾自身のメタデータは弾フォルダ直下に保持します。

```sh
gcc -std=c11 -Wall -Wextra -Wpedantic -Isrc/Shered \
  src/Play/main.c src/Shered/player.c src/Shered/stage.c \
  src/Shered/enemy.c src/Shered/enemy_group.c src/Shered/enemy_settings.c src/Shered/game_font.c \
  -o build/side_scroller.exe -lraylib -lopengl32 -lgdi32 -lwinmm

gcc -std=c11 -Wall -Wextra -Wpedantic -Isrc/Editor -Isrc/Shered \
  src/Editor/main.c src/Editor/editor_ui.c src/Editor/file_dialog.c \
  src/Shered/enemy.c src/Shered/enemy_group.c src/Shered/enemy_settings.c \
  src/Shered/game_font.c src/Shered/player.c src/Shered/stage.c \
  -o build/side_scroller_editor.exe \
  -lraylib -lcomdlg32 -lopengl32 -lgdi32 -lwinmm
```

実行ファイルと必要な DLL は `build` にまとめます。ゲーム本体を起動するには、`build` と同じ階層に `assets` フォルダが必要です。
## エリア管理

エディターでは矢印キーで隣接エリアへ移動します。未作成の方向へ移動すると新しいエリアが作成されます。左上の `Area` から現在のエリアを削除できます。エリア構成は通常の全体保存（`S`）で保存されます。履歴／`Ctrl` + `Z` は廃止され、`Revert saved` で保存済み状態へ戻します。

電波発生装置の `Speed at 100B` は数値欄をクリックして入力し、`Enter` で確定できます。データ弾の速度はこの基準速度を容量の100B単位数で割って計算します。プレビュー容量とデータ弾上の容量表記はB単位です。

ブロックモード中はインスペクターと上部の設定パネルを隠し、導線・データ弾軌道をキャンバス全体で編集できます。端点は速くドラッグしても通過マスを補間します。

### シグナル伸縮ブロック

Effect パレットの紫色の2マスブロックです。インスペクターで通常状態を「伸びる」または「縮む」に設定でき、シグナルを受けると指定秒数だけ逆の状態になります。

- ブロックモードでは短いクリックで右・下・左・上の順に向きを回転し、ドラッグ中はカーソル追従ゴーストを表示して離した位置へ特殊ブロックを移動できます。
- インスペクターの `Preview` は押すたびに一回再生します。シグナルボタンの `Preview signal` は、全プレビュー対応対象を一回だけ再生します。
- 設定の保存は全体保存 `S` です。
