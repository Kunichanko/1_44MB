# 1_44MB

## Source layout

- `src/Play`: 本編とExplorer補助実行形式の入口。
- `src/Editor`: エディター専用の入力・プレイ制御・ファイル選択。
- `src/Shered`: 本編とエディターで再利用するRPG、Explorer、フォントの共通実装。

ゲーム本編の進行状態は `build/Stage/game/StageN` の `runtime_state` とオブジェクトフォルダに保持します。エディターの Settings はビルド時だけ使う静的な編集データです。

## Stage storage

- `assets/Settings/Stage/StageN` keeps editor-only static stage definitions.
- `build/Stage/game/StageN/stage.package` is the single-file package used by `rpg_version.exe`.
- Play creates `build/Stage/game/StageN` or `build/Stage/editor/StageN` for runtime folders and metadata, then clears that directory when play ends.
- Running `zipper.cmd` in a placed Folder renames that Folder to `Zipper`; its own `Inbox` becomes the active Zipper structure.

- Event／NPC／ZipperのFunction列は `Preview all functions` で先頭から通して確認できます。プレビュー中は編集用インスペクターを閉じ、終了または画面クリックで編集前の配置とFunction一覧へ戻ります。
- エディター全体の保存操作は `Ctrl+S` です。

- Function列には Dialogue / Move / Wait / Change draw layer を追加できます。Moveは既定で待ち時間なく次Functionへ遷移し、設定した `Next function after` と `Wait` だけが時間を消費します。Player対象ではwalkアニメーションのON/OFFと速度をプレビュー・本編で共通して使用します。

- エディターではPNG・主人公・NPC・Zipperを通常／ブロックモードのどちらでもドラッグで移動できます。通常はマスにスナップし、`Shift`を押している間は自由位置に配置します。重なった場合は画面上で前に描画されているものを選択します。

- `Image Object` はFolderとは独立した非占有の画像配置物です。Reference Objectパレットで選択してマスをクリックし、表示するPNGを選びます。ブロックや他のImage Objectと同じマスに重ねて置けます。Inspectorで描画順を「最背面」「ブロック前・キャラ後」「最前面」と、PNG／Windows ShellのFolder／File見た目を選べます。ビルド時はデータ弾などと同じ `build/objects` 配下の所有フォルダを作成します。
- PNGを未選択のImage Objectは `SET`、読込失敗は `ERR` で表示されます。通常モード・ブロックモードのどちらでもドラッグで移動でき、通常はマス中心へ揃い、`Shift`を押しながらドラッグすると任意位置へ置けます。右クリックで削除できます。
- Image Objectを選択中に `Ctrl` + `D` を押すと、Inspectorの設定を引き継いで右隣へ複製します。

- `Folder` 配置物はInspectorからPNGの見た目とスケールを設定でき、選択中に `Ctrl` + `D` で右隣へ複製できる。

- ブロックモードの `Reference Object` パレットでは `Folder` を配置できる。配置時に選択中ステージの `build` フォルダ内へ同名フォルダを作成し、Folder Inspectorで名前変更・フォルダを開く操作ができる。`FILE.png` のテキストは選択時に `build/reference_files` へコピーされ、元のPC上のパスはステージに保存しない。選択を変更するとそのマスの前のコピーは置き換わる。

## RPGタイトル画面（rpg_version.exe）

- タイトル画面で「始める」→「初めから」を選ぶとゲームを開始します。「続きから」は未実装です。
- `rpg_version.exe` のプレイ中は右上の `Settings` から設定を開けます。設定は現在画面に半透明で重なり、ゲームを停止したまま状態を確認できます。`戻る` でプレイへ戻り、`タイトルへ` でタイトルへ戻れます。
- エディターでも右上の `Settings` を開けます。こちらはタイトルへ遷移せず、`戻る` のみです。

## 実行ファイル

- `rpg_explorer.exe` は Zipper フォルダ専用の自作 Explorer UI です。Zipper をダブルクリックして開き、フォルダのダブルクリック、上へ移動、更新、ファイル／フォルダのドラッグ移動を行えます。右クリック、新規作成、切り取り、共有は無効です。
- エディターの `Settings` で Zipper のダブルクリック時に開く Explorer を `Virtual` または `Windows` から選べます。選択は全体設定として保存されます。
- `Windows` を選んだ場合、実Explorerで開いた `Inbox` はゲームによる追加・移動・削除をその場で更新します。
- `Stage` 設定の左右矢印、または `Shift`+`←`／`→`（`↑`／`↓`も可）で編集対象ステージを切り替えます。ステージの選択位置は保存・`Revert saved` の対象外です。`Add stage`／`Delete stage` は `S` で保存し、`Revert saved` で保存状態へ戻せます。ステージ背景は同じ `Stage` 設定で PNG と背景・ブロックの明るさを設定でき、エディターとゲーム画面の各エリアを16×8マスに合わせて拡大描画します。未設定の場合、背景は描画しません。
- `Stage` 設定の `Zipper capacity` はステージごとの上限を1KB（1000B）単位で入力し、`Enter` で確定します。ゲーム画面左上の ZIPPER ストレージ表示は、`Q`で開く実Zipperフォルダ全体の更新を反映し、上限を超えても数値は表示したままバーだけを100%で止めます。
- マップ内のキャラクター、Zipper、アイテム、設置物、データ弾は、背景・ブロックと同じ表示ピクセルへそろえて描画します。
- `Stage` 設定では、ビルド後にそのステージへ入った時に一度だけ発動するイベントを設定できます。`Area` 設定では、選択中エリアへ初めて入った時に一度だけ発動するイベントを設定できます。どちらも有効／無効と共通のFunction列（Dialogue／Move）を編集し、`S` で保存、`Revert saved` で保存状態へ戻せます。

- `build/rpg_version.exe`: RPGゲーム
- `build/rpg_editor.exe`: RPGステージ・キャラクター・会話の編集

## RPGエディター

- `Item Property` の受容体: 1ブロックにつき1個を辺に設置すると、導線の始点と未延長の端点を自動作成します。通常モードでは、受容体が付いたブロックを押して離すと設置辺を切り替え、押したままドラッグすると導線を延長できます。
- 導線・受容体: 追加、導線端点のドラッグ、受容体の辺切替は、ブロック編集モードの `Ctrl` + `Z` で戻せます。

- `1`〜`6`: 編集するマップを切替
- `B`: ブロック編集モード。左クリックまたはドラッグで選択中ブロックを配置、右クリックまたはドラッグで削除。画面下部の枠付きパレットで種類を選び、別枠のインベントリ名をクリックした一覧または左右矢印でインベントリを切替。各インベントリには10種類まで登録できる。`Earth`には、半マス幅の縦穴・横穴を持つ通常ブロックもある。`Reference Object`では効果を持たない1マスの`FILE.png`を選べる。Fileは通常モードでクリックするとインスペクターを開き、`Select file`で`assets/Files`を初期表示したPC内のファイル選択画面を開ける。選択したファイルは対象ステージの`build/reference_files`へコピーされ、ゲーム内表示はテキスト形式のみ対応する。配置済みのFileは空きマスへドラッグ移動でき、ゲーム中は近づくとファイル名と`E`の案内を表示し、`E`で内容を開く。表示中は会話中と同じく移動できない。`Effect`には跳ねるブロック、減速ブロック、横2マスの跳ねるブロック、L字3マスの跳ねるブロックがあり、配置済みのものはドラッグで空きマスへ移動できる。特殊ブロックは占有マス形状に従って配置・移動・削除・Undoされるため、構成マスのどこを操作しても全体を扱う。`Item Property`はブロック上へ星アイテムを付与し、配置後に星をクリックするとインスペクターを開く。導線を選ぶと、クリックした始点ブロックと隣接する終点ブロックを接続する。始点・終点を隣接ブロックへドラッグすると通過したマスをつなぎ、既存の導線上へ動かすとその地点まで短縮する。ステージ会話のパネルは表示しない
- `Effect`内のドア: 縦3マスのドアを配置。通常モードでドアをクリックするとインスペクターを開き、`Open` / `Close`で状態を切替。開状態は先頭マスが光る
- `Attachment`: 電波発生装置とデータボタンを、既存ブロックのクリック位置に近い床・壁・天井の辺へ取り付ける。ブロック編集モードでは、設置済みの部品をドラッグして近くのブロック辺へスナップ移動でき、部品を右クリックすると土台を残して削除できる。データボタンはプレイヤーが踏んだ瞬間に、配置済みの電波発生装置からデータ弾を1つずつ射出する。設置内容は全体保存でプレイ画面にも反映される
- 電波発生装置: 通常モードで装置をクリックすると、実弾の `Size / file` と `Speed / KB`、プレビュー専用の仮想ファイル数・容量、プレビューON/OFFを調整できる。プレビュー容量欄はクリックしてKB単位の数値を入力し、Enterで確定する。プレビューは実弾と同じ計算式で見た目と速度を決めるが、電気化してもギミックを動かさない。実際のデータ弾が受容体に当たると、同じ弾が電気として接続された導線を末端まで進み、通過したドアを開く。ブロックモードでは黄色い経路端点をドラッグして、ブロック上を含むマスへ軌道を設定する。
- 左上の `Settings`: 全ステージ共有の `Settings`（Explorer／Build）と `Runtime`（導線／Zipper）を設定する。`Stage` ではステージの切替・追加・削除と背景 PNG を設定する。背景 PNG が未設定のステージでは背景を描画しない。Zipperではフォルダ返却時間と返却開始から演出開始までの遅延を変更できる。`S` で全体保存する。
- ドアに重なる導線: ドア内の部分を薄く表示し、マス境界の接点を強調
- ブロックモードの`Item Property`パレットにある`Event`: 空きマスを左クリックしてマス中央へ配置する。Event上をドラッグすると移動できる。通常モードではクリックして機能を編集し、`Shift`+ドラッグでも移動する。`Event`選択中の右クリックで削除する
- `S`: ブロック・星アイテムを含む編集内容をまとめて保存
- インスペクター: ボタン・入力欄以外の空白部分をドラッグして移動
- Zipper選択表示: エディターではホバーで淡い青、選択中は濃い青で表示。ゲーム中は追従状態のZipperだけ同じクリック選択表示を行う
- File選択表示: `FILE.png`もZipperと同じく、ホバーで淡い青、クリック選択で濃い青になり、別の場所のクリックやプレイヤー移動で解除される
- File取得: Fileに近づいて`G`を押すと、1つだけ小さくなってプレイヤー後方を追従する。次を取得すると前のFileはその場に残る。追従中もクリック、ドラッグ、ダブルクリックで操作できる。縮小率は`Settings`の`File follower scale`で変更できる。Folderは取得せず、追従Fileがある状態で近づいて`P`を押すと、弧を描いてそのFolderへ格納する。
- `assets/Files/zipper.cmd` をFolderへ格納して実行すると、そのFolderがあるエリアでだけZipperが追従状態になります。別エリアで実行した要求は無効です。Folderの`object_info.txt`にはステージ番号・マス座標・CMD名が記録されます。
- ゲーム中のFile操作: `FILE.png`をダブルクリックすると内容を開く。ドラッグ中はカーソルに追従し、元の位置には半透明のFileを表示する。Zipper上で離すとそのプレイ中はステージから消えて、実Zipperフォルダ内の`Inbox`へコピーされる。ほかの場所で離すと元の位置へ戻る
- Zipperディレクトリ: Zipperをダブルクリックすると、Zipper配下だけを扱う自作Explorer UIを別ウィンドウで開く。フォルダやファイルの表示・移動はゲーム側で描画し、Shell APIの実アイコンとWindows標準フォントを使う
- 導線の端点編集は、ほかのグリッド経路機能でも使える共通の経路編集として実装
- 星アイテムの未保存変更: 画面上部とアイテムインスペクターに赤字で表示
- `Ctrl` + `Z`: ブロック編集時は直前のマス変更・星アイテムの付与を戻す。星付きブロックの削除は、ブロックと星を同時に復元する。インスペクター表示中は、編集値・ステージ移動・対象選択・モーダル遷移を戻す。履歴は50件までで、エディターを閉じた後も維持
- `Revert saved`: 未保存の編集内容を直近の保存状態へ戻す
- プレイヤー、NPC、Zipperを選択: クリックでインスペクターを開き、ドラッグで位置を変更
- インスペクター: 右端または下端をドラッグして大きさを変更できる。内容が収まらない場合は、パネル内でマウスホイールを使ってスクロールする。
- 共通ドラッグ: 設置物・特殊ブロック・キャラクター・`FILE.png` は、同じ移動しきい値でドラッグを開始し、ドラッグ中はインスペクターを閉じます。
- エディター内プレイ: 左上の `Play` で、選択中ステージを簡易ビルドして現在のプレイヤー位置から動作確認を開始します。`Stop` でプレイ中の変化を破棄して、開始前の編集状態へ戻ります。開始時に各種プレビューはリセットされ、停止後には復元されません。`All folders` 設定でも開始エリアだけをフォルダ化します。
- エディター内プレイの操作: `E` でNPC会話を進め、`I` でNPCまたはZipperを調べます。Zipperの調べるFunction完了後は追従し、ダブルクリックで本編と同じZipperフォルダを開きます。
- エディター内プレイ中のみ、`Q`で現在接続しているZipperフォルダを開けます。
- 各キャラクターのインスペクター: `Save`でそのキャラクターの位置・大きさだけを保存。隣の`Revert`でその保存状態へ戻す
- Zipper設定: 位置・大きさ・調べるFunctionをZipper専用設定として管理
- Zipperを調べる: 設定したFunction列が完了すると主人公へ追従
- 未保存の変更がある状態で閉じる: 保存して終了／保存せず終了／キャンセルを選択。`Show details`で未保存項目を確認し、一覧はマウスホイールでスクロール

NPCの `Edit dialogue` では通常会話を、`Edit examine` では調べる機能を編集できます。Examineではタイトル付きの会話機能を管理し、各機能ごとに会話を編集します。

- `Edit dialogue`: NPCに話しかけた時の会話を編集
- `Edit examine`: NPCを調べた時の機能一覧を開く
- Examine一覧: 1クリックで会話機能を選択してタイトルを編集、ダブルクリックで会話内容を編集。`Add function` で機能タイプを選択して追加、右クリックで削除、会話ブロックをドラッグして順番変更
- Move機能: 実際のゲームでは選択対象の本体を移動させる。対象選択は描画上もっとも前の対象を選ぶ。`Select target`を押すと設定パネルが隠れ、対象をクリックするまでマップだけが操作を受け付ける。AxesでXのみ／Yのみ／XY移動を選び、パネル外の左クリックで有効な軸の目的地を設定する。通常は終点をマスにスナップし、`Shift`を押している間は自由位置を指定できる。終点はマーカーで確認できる。補間はEasingを押して一覧から選択する。`Duration`は移動の所要時間、`Next function after`は開始から次のFunctionへ進むまでの時間であり、移動より短くしても移動は継続する。プレビューは選択対象の現在位置から開始し、同じ見た目のダミーだけを移動させるため実際の配置は変更しない。各`Save`の隣の`Revert`はその編集内容だけを戻し、全体保存は`S`で行う。サイドパネルの空白部分はドラッグで移動可能
- モーダル画面: `Tab` で一つ前の画面へ戻る。Examineの会話編集は一覧へ、一覧ではエディター画面へ戻る
- Zipper: インスペクターの `Edit examine` から調べる機能を編集

## RPGゲーム

`Global Settings` の `Build cell storage` では、通常マスを `Compact`（`cells_metadata.txt` に集約）と `All folders`（空気を含む全マスを個別フォルダ化）から選べます。本編の `All folders` はプレイヤー開始エリアを先に生成し、残りをゲーム開始後に少しずつ生成します。エディター内プレイは設定に関係なく開始エリアだけを生成します。ビルド開始時には、選択中の方式で対象ステージの `build` を一度クリアして再生成します。

`Attachment` パレットの Save flag は触れた旗を復帰地点として保存します。タイトルの `続きから` は保存したステージ・旗・Zipper接続状態で再開します。

Zipperの取り込み操作は `Settings/Zipper/Inbox/assyuku.vbs` を実行します。コンソールを開かずにcmdと同じ取り込み要求を出します。`assyuku.cmd` は既存操作との互換用です。

`Attachment Object` パレットの射出装置と Save flag は、ブロックと空気の境界に配置する1マス占有物です。占有マスには通常ブロックを配置できません。`Attachment Edge` のボタンと受容体は従来どおり辺に取り付けます。

- 移動: `A` / `D` または矢印キー
- ジャンプ: `W`
- Zipper射出: Zipperを調べ終えた後、追従中に`Space`。プレイヤー位置からマウスカーソル方向へ直進し、ブロックに当たると停止します。停止後にもう一度`Space`で追従へ戻ります。射出・帰還速度と、射出→帰還を繰り返すプレビューはZipper Inspectorで設定できます。
- 主人公スプライト: `assets/Sprite/EXE` の `EXE_walk.png` を通常・移動、`EXE_jump.png` をジャンプ、`EXE_zipgo.png` をZipper射出中に使用します。
- タイトル画面: `始める` → `初めから` の後に、存在する各ステージの `［Stage番号］をビルドする` を選んで開始します。選択するたびに `assets/Settings/Stage/Stage番号/build` を完全に削除して作り直します。空気と通常ブロックは `cells_metadata.txt` に集約し、特殊ブロックと設置物だけを個別objectフォルダとして生成します。
- Zipperが空気・通常ブロックを取得した時だけ、そのマスの行を `cells_metadata.txt` から取り出してobjectフォルダへ変換します。取り出し中のマスは赤い壁として扱います。
- 本編中は `build` 以下を変更通知で監視します。マスのobjectフォルダを外部で削除すると、そのマスは赤い壁になります。外部ファイルの強調表示も、変更通知を受けたマスだけ更新します。Zipperで取得したフォルダは `build` と `Settings/Zipper/Inbox` の間を移動します。
- 返却先は実行中ステージの `build` 配下だけです。Compact方式で一度取得した通常マスは再圧縮せず、`build/cells` の実フォルダとして読み込みます。
- 本編中の `設定` では `戻る` または `タイトルへ` を選べます。タイトルから開始し直す時は、同じステージを選んだ場合も実行状態を初期化します。
- Zipperのobjectフォルダ: 電波装置・ボタンなどの設置物には、配置情報を記録したobjectフォルダを`Stage/Objects/attachments`へ用意します。設置物に接触中に`Inbox/assyuku.cmd`を実行すると、通常ブロックと同じ一時コピー・変更通知・同期を利用します。紐づくファイルを持つ設置物は金色で、通常ブロックはそのマス自体を強調表示します。Zipperのダブルクリックは常にZipperフォルダを開きます。
- Zipper取り込み: cmd実行で接触中のobjectフォルダをInboxへ取得すると、Zipperは追従へ戻ります。帰還操作では取得済みフォルダをInboxに保持し、次のcmd実行で前回分を戻してから現在の接触対象を取得します。
- Zipper返却演出: `Global Settings` の `Folder return` で演出時間を設定できます。cmd入力時に旧フォルダを対象ステージ直下へ待機させ、返却演出の完了時に `build` へ戻します。
- cmd処理順: 取り込みアニメーションの終了時に、返却演出の完了を待たずZipperの帰還と次の対象の取り込みを確定します。
- 1マス占有の配置物（電波装置・旗）は取り込み中に非表示・停止し、占有マスを赤いエラー壁として表示します。返却時に元の空きマスへ戻ります。
- 射出中のZipper: ブロック、`FILE.png`、電波発生装置、データ弾に接触すると停止します。データ弾へ接触した場合は消えるまで追従し、壁へ衝突して消えた弾には壁際へ残り、空中で消えた弾からは追従状態へ戻ります。
- データボタン: `Attachment` パレットから既存ブロックの辺へ取り付けます。プレイヤーが踏むと、ボタン押下通知を発行します。現時点では電波発生装置がこの通知を受信し、データ弾を射出します。
- グリッドのブロックと閉じたドアは壁として当たたり、開いたドアは上1マスだけ壁として残り、下2マスはプレイヤーとデータ弾が通行できます。
- NPC会話: `E`
- NPC・Zipperを調べる: `I` で開始、`E` で進行。一度完了すると、そのゲーム中は再実行しない
- 星アイテム: 近づくと取得し、入手メッセージを表示
- カメラ切替: `C`

RPGのステージ・会話・配置物・履歴は `assets/Settings/Stage`、Zipperの設定は `assets/Settings/Zipper`、全ステージ共有のRuntime設定は `assets/Settings/rpg_global_runtime.cfg` に保存します。プレイ中に回収したテキストFileは `Settings/Zipper/Inbox`、objectフォルダは `Settings/Stage/Objects` を一時利用します。ゲーム開始時と終了時には、これらとZipper直下の一時objectコピーを確認して削除します。画像やフォントなどの外部ファイルは `assets` に置き、`build` には追加しません。
- `build`: 実行ファイルと必要な DLL
- `experiment`: 実験用スペース（各自ローカル。`.gitignore` 済み。詳細は `experiment/README.md` と `experiment/RULES.md`）

## ステージグリッド

ステージは32px四方・1エリア16×8マスのグリッドで管理します。標準サイズのプレイヤー、NPC、Zipperは1マス内に収まります。旧グリッドのブロック配置は、新しい地面のみの状態へ初期化されます。

- `0`: 空白
- `1`: 地面・壁ブロック
- `2`: 敵がいるマス（敵の移動に合わせて更新）

## 操作

- `A` / `←`: 左へ移動
- `D` / `→`: 右へ移動
- `Space`: 主人公のアクションを一度再生。アニメーション中は移動できず、220px以内の敵を従属化する。紫の円が判定範囲
- `Q`: グリッド確認モードを切替。画面を淡くし、各マスの `0` / `1` / `2` を表示
- `Esc`: 終了

## エディター

`build/rpg_editor.exe` を起動すると、ステージを確認・編集できます。

- 主人公を左クリックするとインスペクターを表示します。
- インスペクターの「PNG を選択」から PNG ファイルを指定すると、その場で見た目に反映されます。
- プレイヤーと敵は標準で1.5倍の大きさで表示されます。各インスペクターの `Scale` で0.5〜3.0倍に変更できます。
- 敵を左クリックすると敵インスペクターを表示し、追従間隔・補間速度・従属時の色を変更できます。
- インスペクターを開いたクリックはボタン操作として扱わず、インスペクター外を左クリックすると閉じます。
- 追従間隔と補間速度はスライダーのほか、右側の数値欄をクリックしてキーボード入力でも変更できます。最初のクリック後に数値を入力すると値全体を上書きし、同じ欄をもう一度クリックすると、その桁の位置から編集できます。Enterで確定します。保存結果は敵インスペクター下部に表示されます。
- プレイヤーと敵の `Scale` 入力欄は独立しており、片方を編集した値がもう片方へ引き継がれることはありません。
- 「設定を保存」で `assets/Settings/enemy_settings.cfg` に保存され、保存成功時は敵インスペクターが閉じます。ゲーム本体の次回起動時に反映されます。
- Playボタンでエディター内の動作確認を開始できます。停止中は敵は動かず、Play中はゲーム本体と同様に `A` / `D` と `Space` を操作できます。
- エディターでも `Q` でグリッド確認モードを切り替えられます。
- Playボタン横の `Global` を押すと全体インスペクターを開けます。`Grid opacity` で、グリッド確認モード時に画面を淡くする度合いを変更・保存できます。

## オブジェクトフォルダ

設置物とデータ弾は固有の実フォルダを持ち、Zipper のアニメーション中はそのフォルダ本体を `Settings/Zipper/Inbox` へ移動します。データ弾は取り込み中に停止・非表示となり、返却時には`object_info.txt`へ統合したマス位置と親装置の軌道位置から復帰します。データ弾が消える際には、発射後に追加されたファイルだけを File.png として地面へ落として保持します。

電波発生装置が出すデータ弾は、弾フォルダ内のファイル数から1を引いた値で大きさ、合計容量で速度を決めます。発射時には装置側のメタデータ・ファイルを弾フォルダの `parent` へ複製し、弾自身のメタデータは弾フォルダ直下に保持します。

実行ファイルと必要な DLL は `build` にまとめます。ゲーム本体を起動するには、`build` と同じ階層に `assets` フォルダが必要です。
## エリア管理

エディターでは矢印キーで隣接エリアへ移動します。未作成の方向へ移動すると新しいエリアが作成されます。左上の `Area` から現在のエリアを削除できます。エリア構成は通常の全体保存（`S`）で保存されます。履歴／`Ctrl` + `Z` は廃止され、`Revert saved` で保存済み状態へ戻します。

電波発生装置の `Speed at 100B` は数値欄をクリックして入力し、`Enter` で確定できます。データ弾の速度はこの基準速度を容量の100B単位数で割って計算します。プレビュー容量とデータ弾上の容量表記はB単位です。

ブロックモード中はインスペクターと上部の設定パネルを隠し、導線・データ弾軌道をキャンバス全体で編集できます。端点は速くドラッグしても通過マスを補間します。

### シグナル伸縮ブロック

Effect パレットの紫色の2マスブロックです。インスペクターで通常状態を「伸びる」または「縮む」に設定でき、シグナルを受けると指定秒数だけ逆の状態になります。

- ブロックモードでは短いクリックで右・下・左・上の順に向きを回転し、ドラッグ中はカーソル追従ゴーストを表示して離した位置へ特殊ブロックを移動できます。
- インスペクターの `Preview` は押すたびに一回再生します。シグナルボタンの `Preview signal` は、全プレビュー対応対象を一回だけ再生します。
- 設定の保存は全体保存 `S` です。
